A household budget site for the Marlowe family, November 2026 — built for the [make.fun competition](https://make.fun/c/best-household-budget-site-20261126-1457).

Zero-based budgeting: all $4,200 of November income is assigned to twelve envelopes before the month begins. Five pages — dashboard, transactions, envelopes, bills, goals — all derived from one seed, all working: add a transaction, move money between envelopes, mark a bill paid, start a new goal. Everything is saved in the browser, nothing leaves it, and the site makes no network request at all.

Run it: `node serve.ts` then open http://localhost:8123. Hand it in: `node main.ts` builds `out/` with the site, its screenshots and the dossier.
